# خطة تنفيذ «أدواتي» (Toolbox)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**الهدف:** منصة أدوات شخصية (PWA) على GitHub Pages، أول أداة فيها المصاريف الشهرية، بمزامنة مشفّرة بين أجهزة المالك ووضع محلي للآخرين، بالعربي والإنجليزي.

**البنية:** ملفات ثابتة بـ JavaScript (ES modules) بدون خطوة بناء. المنطق في وحدات صغيرة نقية تُختبر في Node، والواجهة تقرأ منها وتكتب عبر طبقة تخزين واحدة (IndexedDB). المزامنة ترفع نسخة مشفّرة من الحالة كاملة إلى مستودع خاص عبر GitHub REST API، وتدمج بالحركات لا بالاستبدال.

**التقنيات:** HTML/CSS/JS بدون إطار عمل · Web Crypto (PBKDF2 + AES-GCM) · IndexedDB · Service Worker · `node --test` للوحدات · Playwright لاختبارات الواجهة فقط (devDependency).

**وثيقة التصميم:** [وثيقة تصميم «أدواتي»](https://claude.ai/artifact/FjZF9qNpauTG9dDzsdktuu) — ونسخة مختصرة في `docs/superpowers/specs/2026-11-15-toolbox-design.md`. النموذج المعتمد بصرياً: [أدواتي — زجاجي](https://claude.ai/artifact/5zThQvxxu23WoX9s4xQiJV).

## Global Constraints

- الاستضافة: GitHub Pages، مستودع عام `toolbox` على حساب `saad-00`، الرابط `https://saad-00.github.io/toolbox/`.
- البيانات: مستودع خاص `toolbox-data`، ملف واحد `toolbox.enc.json`. لا بيانات ولا مفاتيح في المستودع العام أبداً.
- المفتاح: Fine-grained token بصلاحية Contents (قراءة وكتابة) على `toolbox-data` وحده، يُحفظ على الجهاز فقط.
- التشفير: AES-GCM 256، المفتاح من كلمة السر بـ PBKDF2-SHA256 بـ 600000 تكرار، ملح 16 بايت وIV بطول 12 بايت جديدان مع كل رفع. كلمة السر لا تُحفظ ولا تُرفع.
- المبالغ: تُخزّن أعداداً صحيحة بالهللة (×100)، وتُعرض بأرقام لاتينية وفاصلتين عشريتين عند الحاجة، بالريال «ر.س» / «SAR».
- اللغة: الأساسية = لغة الجهاز؛ `ar*` → عربي، `en*` → إنجليزي، غيرها → إنجليزي. العربي `dir=rtl` والإنجليزي `dir=ltr`. الخط Alexandria للغتين.
- التصميم: زجاجي، اللون الأساسي «جرافيت» (`bg #14161b`، `b1 #556072`، `b2 #7d8798`، `b3 #2c3644`)، وستة ألوان أخرى + «ألوانك» خيارات في الإعدادات.
- النصوص المثبتة: نافذة التسجيل «سجّل صرف» / "Log spending" وزرها «سجّل» / "Log"؛ التأكيد «أُضيف {amount} ر.س إلى تم الصرف · {cat}»؛ نافذة الأقساط «أضف قسط» / "Add installment".
- الأقساط: من 1 إلى 48 شهراً، الدفعة = الإجمالي ÷ العدد، والفرق يُضاف لآخر دفعة.
- الشهر الجديد ينسخ دخل وميزانية آخر شهر سابق تلقائياً، وتعديله لا يغيّر الأشهر السابقة.
- حاسبة المدة التنفيذية ليست من أدوات المنصة.
- حذف أي حركة أو قسط أو بند = علامة `deleted: true` مع `updatedAt`، لا مسح.

## Review Focus

1. **إدخال المبلغ بصيغ مختلفة:** «١٬٥٠٠٫٥» و«1,500.5» و«1500» تعطي 150050 هللة؛ الفارغ والصفر والسالب والنص يُرفض برسالة. → اختبارات في المهمة 1.
2. **أخطاء الكسور العشرية:** 171.75 + 50 + 41 = 262.75 بالضبط، ومجموع نوفمبر يطابق Excel. → التخزين بالهللة، اختبار في المهمة 6.
3. **جهازان يرفعان في نفس الوقت:** GitHub يرد 409 عند اختلاف `sha`؛ المتوقع إعادة السحب والدمج والرفع مرة واحدة دون فقد حركة. → اختبار في المهمة 10.
4. **كلمة سر خاطئة على جهاز جديد:** المتوقع إيقاف المزامنة برسالة واضحة، وعدم رفع أي شي يمسح النسخة البعيدة. → اختبار في المهمة 10.
5. **تاريخ على حدود الشهر:** حركة بتاريخ `2026-11-30` مُدخلة بعد منتصف الليل بتوقيت الرياض تبقى في نوفمبر؛ الشهر يؤخذ من نص التاريخ لا من `Date` بتوقيت UTC. → اختبار في المهمة 4.
