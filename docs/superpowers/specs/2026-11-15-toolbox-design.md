# وثيقة تصميم «أدواتي» (Toolbox) — نسخة مختصرة

النسخة الكاملة والمحدّثة: https://claude.ai/artifact/FjZF9qNpauTG9dDzsdktuu
النموذج البصري المعتمد: https://claude.ai/artifact/5zThQvxxu23WoX9s4xQiJV

- منصة أدوات شخصية PWA على GitHub Pages (`saad-00/toolbox`)، أول أداة: المصاريف الشهرية.
- المعادلات: تم الصرف = الحركات + الدفعات المدفوعة؛ المجموع الفعلي = الميزانية + الدفعات المستحقة؛ الباقي الحالي = الدخل − تم الصرف؛ الباقي الفعلي = الدخل − المجموع الفعلي.
- الأقساط 1–48 شهراً، الفرق لآخر دفعة. الشهر الجديد ينسخ السابق تلقائياً دون تغيير الماضي.
- البيانات على الجهاز (IndexedDB)، ومزامنة المالك بنسخة مشفّرة (AES-GCM + PBKDF2) في `saad-00/toolbox-data` بمفتاح محدود، والدمج بالسجلات.
- الآخرون: وضع محلي افتراضي، شاشة ترحيب ببنود جاهزة قابلة للإزالة، نسخة احتياطية وتذكير كل 30 يوماً.
- اللغة: لغة الجهاز (ar أو en، وغيرها en)، والإنجليزي يقلب الاتجاه.
- التصميم: زجاجي، جرافيت أساسي، وستة ألوان + «ألوانك» في الإعدادات. خط Alexandria.
- ليس ضمن المنصة: حاسبة المدة التنفيذية، أي أداة متعددة المستخدمين، الربط بالبنك.
